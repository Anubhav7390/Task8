# 📊 Sales Data Analysis & Dashboard Visualization

## 🔍 Project Overview
This project involves end-to-end data analysis and visualization using Python (Pandas) and Tableau. The goal was to explore sales data, clean it, extract insights, and present them through an interactive dashboard.

### Workflow Summary

1. **Data Source**
   - Imported raw dataset from [Kaggle](https://www.kaggle.com/) (e.g., Superstore Sales or similar dataset).

2. **Data Cleaning (Python)**
   - Used **Pandas** to:
     - Handle missing values
     - Fix incorrect data types
     - Standardize formatting
     - Remove duplicates and irrelevant columns
   - Performed **Exploratory Data Analysis (EDA)** to understand distributions, outliers, and correlations.

3. **Data Export**
   - Exported the cleaned dataset to a `.csv` file for external use.

4. **Data Visualization (Tableau)**
   - Imported the cleaned CSV into Tableau Public/Desktop.
   - Created various visualizations:
     - Sales by state and region
     - Monthly trends
     - Top customers and sub-categories
     - Category-level and segment-level analysis
   - Combined all insights into a **dynamic dashboard**.

###  Dashboard Features
- Interactive map of U.S. state-wise sales
- Time-series line chart for monthly sales trends
- Pie chart for category-wise sales contribution
- Stacked bars for sub-category and segment breakdown
- Top 10 customers by total sales
- Regional sales comparison

### Tools Used
- **Python** (Pandas, Matplotlib, Seaborn for EDA)
- **Jupyter Notebook / VS Code**
- **Tableau Public** (for dashboard)
- **Kaggle** (data source)

### Output
- Final dashboard exported from Tableau.
- Cleaned dataset stored in `/data/cleaned_sales_data.csv`
- Visuals and insights available in `/dashboard/` or screenshots folder.
